## Description

A locket recovered from Thomas Manuel's apartment. Used by Mortimer to distract Castaigne while Marlowe searched his bedroom in Session 4.

## Significance

In Session 7, the children's book *Maude Goes to the Masked Ball* was found in Michelle Vanfitz's library — its illustrations depict a character named Ambrose wearing what appears to be this exact locket. The connection between Thomas Manuel and this specific storybook artifact is unexplained.
